🗄️ MongoDB 连接测试

通过 Vercel Serverless Function 读取数据库和集合；连接字符串不会暴露到前端
在 Vercel 部署后默认地址就是 /api/mongo-test。
如果你把 HTML 单独部署到其它地方，可改成完整地址，如 https://sleep-story.vercel.app/api/mongo-test。
⚠️ 这个页面本身不处理 MongoDB 连接字符串；凭据由 Vercel Function 从环境变量读取，不会泄露到浏览器。
点击上方按钮后，这里会列出所有数据库和每个库里的集合。
本地测试脚本用法 
# 1) 确认 Vercel CLI 已登录并已 link 项目
vercel env pull

# 2) 运行本地脚本
node scripts/mongo-test.mjs

# 或一次性指定 URI
MONGODB_URI="你的连接字符串" node scripts/mongo-test.mjs
